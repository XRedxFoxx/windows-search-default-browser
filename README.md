# Windows Search - Search Engine Redirect

A Windhawk mod that lets you customize the search engine used by Windows Search and open web results in your default browser instead of Microsoft Edge.

## Features

- **Custom Search Engine:** Choose your preferred search engine.
- **Supported Search Engines:**
  - Google
  - Bing
  - DuckDuckGo
  - Yahoo
  - Brave Search
  - Ecosia
  - Startpage
- **Custom Search URL:** Add your own search engine using a URL template with `{query}` as the search term placeholder.
- **Default Browser Redirect:** Open Windows Search web results in your default browser instead of Microsoft Edge.

## Requirements

- Windows 11
- [Windhawk](https://windhawk.net/)

## Installation

1. Install [Windhawk](https://windhawk.net/).
2. Open Windhawk.
3. Find **Windows Search - Search Engine Redirect** (once published).
4. Install and configure the mod.

## Configuration

Open the mod's settings in Windhawk to:

- Select a search engine.
- Enter a custom search URL template.

## Compatibility

Designed for Windows Search processes:

- `SearchHost.exe`
- `SearchApp.exe`
